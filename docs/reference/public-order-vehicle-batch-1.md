# Stage 36A Public Order Vehicle Batch 1

This branch applies the first official vehicle-enrichment batch for issue #20.

The authoritative source is the MissionChief UK Help Centre article covering PSU vehicles. It verifies PSU Carrier, Firearms Personnel Carrier, Multiple Dog Carrier, Detention Van, Mounted Unit and M-RAV, including their current costs, crew ranges, training requirements and published transport capacities.

This file exists to provide a permanent reviewer-visible evidence note. Generated coverage and public API outputs are updated by the batch workflow.
