# Verified Vehicle Enrichment Batch 2

This Stage 36A batch applies current official UK Help Centre economics and operating contracts to 21 existing canonical resources.

## Scope

- Coastguard, Lifeboat and technical water-rescue vehicles and trailers;
- UK foam-capable fire vehicles;
- UK drone equipment;
- patient and prisoner capacity;
- formal towing and resource-class contracts.

## Evidence policy

Only values explicitly published by the official UK Help Centre are promoted. Unpublished defaults, crew values and market restrictions remain omitted. The current game type IDs remain separately evidence-tiered in the vehicle source ledger.
