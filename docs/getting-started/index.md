# Getting Started

Use this section to move from an empty or early account into a sustainable multi-service network without activating mission pressure faster than the fleet, personnel and geography can absorb it.

!!! info "Evidence boundary"
    The sequence below is recommended strategy. It does not invent universal credit reserves, station counts or unlock thresholds. Exact mission, resource and infrastructure facts remain in the canonical reference database and service guides.

## Start with the operating loop

1. Build routine Fire, Police or Ambulance capability in a practical response area.
2. Complete the missions already generated before adding another generator.
3. Record recurring shortages: quantity, journey time, personnel, training, transport or infrastructure.
4. Correct the narrowest measured bottleneck.
5. Protect a useful routine reserve.
6. Test two representative incidents together.
7. Expand one controlled step.
8. Observe the changed mission mix before repeating.

## Foundation readiness

A foundation network should be able to:

- dispatch its common local incidents;
- leave some useful routine cover after a normal response;
- provide correctly staffed and trained units rather than owned-but-unusable vehicles;
- handle basic patient or prisoner movements where those services are active;
- recover vehicles and personnel to useful geography;
- explain which shortages require local correction and which are temporary alliance contingencies.

Do not count a future purchase, untrained vehicle, unavailable crew or unverified substitution as current capability.

## Account archetypes

### Dense urban

Prioritise short route times, high concurrency, hospital/custody throughput and distributed routine cover. Specialist hubs can work well, but only when ordinary demand remains protected.

### Rural

Prioritise road topology, bridge and mountain access, relief locations and travel-time resilience. A resource that exists but cannot reach its mission family promptly is not effective coverage.

### Coastal

Separate road response from launch, vessel, trailer, towing and air-rescue chains. Place resources around real access points rather than visual coastline spacing.

### Alliance-supported

Alliance support can defer an expensive specialist capability, but should remain a named contingency with known travel time and donor reserve. It must not hide persistent local routine deficits.

## First-session checklist

- [ ] Choose a compact operating area with usable road access.
- [ ] Build one coherent routine service before scattering stations.
- [ ] Learn the distinction between guaranteed, alternative, conditional and probabilistic requirements.
- [ ] Keep personnel and training attached to vehicle decisions.
- [ ] Check likely hospitals, custody destinations and cross-service partners.
- [ ] Record mission pressure before purchasing another specialist.
- [ ] Use the readiness planner with blank fields left unknown rather than guessed.
- [ ] Expand only after the current network returns to a stable operating state.

## Common early mistakes

1. adding buildings because credits are available rather than because capability is ready;
2. treating vehicle ownership as proof of trained staffing;
3. using alliance assistance as permanent routine cover;
4. placing stations by equal map circles instead of routes and destinations;
5. activating an extension before its personnel, vehicles and partner services are commissioned;
6. filling unknown prices, capacities or unlock rules with assumed values;
7. expanding again before patient, custody or recovery cycles have returned resources to service.
